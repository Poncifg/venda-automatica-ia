# Módulo 02 — WhatsApp Automático

## Objetivo
Transformar o WhatsApp em uma máquina de atendimento e conversão.

## O que você vai aprender
- Como responder automaticamente
- Como criar sequência de mensagens
- Como fazer follow-up sem parecer spam
- Como usar modelo de atendimento humano e automatizado

## Estrutura de atendimento
### Etapa 1: Boas-vindas
- mensagem de confirmação
- pergunta inicial
- apresentação da oferta

### Etapa 2: Qualificação
- entender a necessidade
- confirmar interesse
- mover para a venda

### Etapa 3: Fechamento
- resumo da proposta
- CTA direto
- prova ou depoimento

## Sequência sugerida
1. Mensagem de boas-vindas
2. Pergunta sobre problema
3. Apresentação da solução
4. Follow-up 24h depois
5. Oferta final com CTA

## Templates prontos
- Mensagem para lead frio
- Mensagem para lead quente
- Mensagem para cliente desistente
- Mensagem para venda direta

## Tarefa de saída
Crie 3 sequências de mensagens para uma oferta digital.
