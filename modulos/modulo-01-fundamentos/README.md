# Módulo 01 — Fundamentos da Venda Automática

## Objetivo
Crie uma base sólida para vender sem depender de sorte ou improviso.

## O que você vai aprender
- Como funciona um funil de vendas simples
- Como escolher uma oferta que resolve um problema real
- Como atrair clientes sem depender de grandes investimentos
- O que faz uma mensagem vender
- Como automatizar atendimento e follow up

## Conteúdo do módulo
### 1. O que é venda automática
Venda automática é a combinação de:
- oferta clara
- mensagem bem escrita
- automação de atendimento
- follow-up em sequência
- CTA forte

### 2. Estrutura de um funil simples
1. Atração
2. Interesse
3. Conversão
4. Retenção

### 3. O que vende hoje
Produtos e serviços com:
- solução rápida
- dor clara
- prova simples
- preço acessível

### 4. Erros comuns
- Oferta confusa
- Sem proposta de valor
- Sem seguimento após o interesse
- Mensagens genéricas

## Exercício prático
Crie 3 ideias de oferta para 3 públicos diferentes:
- pequenos negócios
- freelancers
- iniciantes digitais

## Tarefa de saída
Escolha um público e monte uma oferta em 3 linhas.
